# TalkingHeart для Windows — установщики

Здесь публикуются готовые сборки приложения TalkingHeart для Windows (анализ RR-интервалов / ВСР).
Исходный код — в отдельном закрытом репозитории.

## Установка
1. Откройте [Releases](../../releases) и скачайте `TalkingHeart-Setup-<версия>.exe`.
2. Запустите установщик. Права администратора не нужны. Если Windows SmartScreen предупредит
   о неизвестном издателе — «Подробнее» → «Выполнить в любом случае» (сборка не подписана сертификатом).

## Обновления
Приложение само проверяет эту страницу («Справка → Проверить обновления»):
- `TalkingHeart-Setup-X.Y.Z.exe` — новая версия приложения (ставится поверх, записи сохраняются);
- `core-X.Y.Z.zip` — обновление только ядра расчёта, без переустановки.

## Откат
- Ядро: в приложении «Справка → Вернуть встроенное ядро».
- Приложение: скачайте установщик предыдущей версии из Releases и установите поверх.

Данные пациентов здесь не хранятся.
